# Chop Smart — installable web app

This is a free Progressive Web App (PWA) starter for the Chop Smart weekly Ghanaian meal planner.

## What it does
- Installs to an Android home screen from Chrome when hosted over HTTPS.
- Has a standalone app-like window.
- Caches the app shell for offline reopening after the first successful visit.
- Stores the meal plan in browser local storage when available.

## Publish it for free with GitHub Pages
1. Sign in or create a free account at https://github.com/
2. Create a new **public** repository named `chop-smart`.
3. Choose **Add file → Upload files**.
4. Upload the five files in this folder: `index.html`, `manifest.webmanifest`, `service-worker.js`, `icon-192.png`, and `icon-512.png`.
5. Commit the files.
6. Open the repository's **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
8. Wait for GitHub Pages to provide a website address. Open that HTTPS address in Chrome on your Samsung Galaxy A17.
9. In Chrome, tap ⋮ → **Install app** or **Add to Home screen**. The exact wording varies.
10. Open the new Chop Smart icon from your home screen.

## Important
- This creates an installable PWA, not an APK and not a Google Play Store listing.
- You do not need to pay to use GitHub Pages for a public repository.
- Do not upload passwords, private data, or secret keys to the repository.
- The app's meal and shopping suggestions are general ideas, not price quotes.
